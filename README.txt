Portfolio website with project image spaces.

Open index.html first.

To add your own project pictures:
1. Keep your image files inside this same folder.
2. Rename your images exactly:
   project1.png
   project2.png
   project3.png
   project4.png
   project5.png
   project6.png
3. Replace the existing placeholder images with your own images.
4. Push all files to GitHub.

Important files:
- index.html
- projects.html
- profile.png
- project1.png to project6.png
